# Hausklima

Web-App für ThermoPro/TempPro-Sensoren (TP357, TP358, TP359, TP357S): Verlauf per Bluetooth abrufen, lokal im Browser speichern und auswerten – Feuchtephasen, erkannte Lüftungen, Empfehlungen je Raum.

- Läuft in Chrome auf Android und am PC (Web Bluetooth), über GitHub Pages.
- Messwerte bleiben im Browser des Geräts, nichts davon landet in diesem Repository.
- Außenwetter von Open-Meteo, Wohnort in den Einstellungen der App eintragen.

Das Bluetooth-Protokoll ist inoffiziell und stammt aus den Projekten pasky/tp357, alexpacini/tpy357 und giovannipizzi/pytp357s.
